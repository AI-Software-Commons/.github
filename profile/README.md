# AI Software Commons

Open-source AI and ML software: inference runtimes, model optimisation and sparsity
tooling.

## Mission

Keep the software that runs and shrinks machine-learning models open, readable and
reusable. We host and track the inference and optimisation projects we depend on, so the
work stays available and the history stays intact.

## Focus areas

- **Large language model serving** - `text-generation-inference`, a text generation
  server for large language models.
- **Model-specific inference** - `mistral-inference`, the official inference library for
  Mistral models.
- **CPU inference** - `deepsparse`, a sparsity-aware deep learning inference runtime for
  CPUs.
- **Model optimisation** - `sparseml`, libraries that apply sparsification recipes to
  neural networks, and `sparsify`, a product that accelerates inference.
- **Measurement** - `inference-benchmark`, for comparing runtimes.

Every repository here keeps the license of its upstream project.

## How to contribute

1. Open an issue on the repository the change belongs to. Describe the problem before you
   write code.
2. Fork that repository and work on a branch.
3. Open a pull request against `main`. Explain what you changed and how you tested it.
4. Follow the upstream project's own contribution guide and code style where one exists.
